    What this check can and cannot tell you

    JPEG only. This prototype reads supported EXIF location, date & time, camera / lens identifiers, and embedded JPEG or JFIF thumbnails. A count is the number of detected groups, not individual tags. Multiple matching tags and EXIF blocks are checked together.

    Unsupported blocks (including XMP, IPTC, ICC profiles, comments, and MakerNotes), GPS timestamps, unreadable values, damaged files, or failed re-reads mean Unknown. Removal and download are blocked when the check is incomplete. “Not found” refers only to supported fields; this tool never declares a photo safe.

    Visible faces, addresses, reflections, text, the original filename, and information added by a sharing service are outside this check. A thumbnail may contain an earlier image, so it is treated as one removable group without displaying it. Additional metadata inside a thumbnail also makes the check incomplete.

    Files stay in memory in this tab. No storage, analytics, or network requests are used. Processing has a 6-second limit per operation and can be cancelled. Closing the tab or starting over clears the app’s references; it cannot promise secure erasure of browser memory. Downloaded copies are separate files with a new generic filename.
